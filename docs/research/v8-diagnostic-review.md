# Независимая проверка v8: Pro high, rules и examples

**Оба варианта не прошли фактический барьер.** У `rules` в #826 бесплатный каталог Docker объединён с SLA платного тарифа. У `examples` в #464 из локального размещения evaluator выведена безусловная гарантия, что код не покидает компанию. Эти ошибки нельзя компенсировать хорошим сжатием или правильным выделением заголовка.

Для дальнейшего исследования `rules` предпочтительнее: он не добавляет ненужных цитат, компактнее на #82 и осторожнее с объектом измерения на #1152. Это выбор рабочего направления, **не одобрение промпта для включения пользователю**. Результаты одного запуска на каждый случай не оценивают частоту ошибок модели.

## Материал и метод

Прочитаны все десять итоговых `message.content` запусков `post-eval-{1107,82,464,826,1152}-{rules|examples}-v8-pro-high` из `.inoreader-state/style-research/experiments/budget.json`. Все использовали `deepseek-v4-pro`, thinking high, `max_tokens=8192`. Рассуждения модели не использовались как доказательство качества итогового ответа.

Для всех десяти запросов проверено точное совпадение `ARTICLE_SNAPSHOT.text` с полными локальными источниками. Все пять источников прочитаны полностью в этой цепочке проверок; повторно проверены места, подтверждающие спорные утверждения. Авторские references этих пяти ID уже были раскрыты; новые FINAL02 references и outputs не читались. Код, промпты и outputs не менялись, API не вызывался.

Номера строк ниже относятся к `.inoreader-state/style-research/sources/final-{1107,82,464,826}-jina-body.txt` и `sources/validation-1152-jina-body.txt`. `Definite` означает конкретное противоречие или неподтверждённое усиление, `caution` — неоднозначность/недостающую оговорку без однозначно ложного утверждения. Это проверка верности пересказа источнику, не независимый аудит заявлений компаний.

## Подтверждённые блокирующие ошибки

### #826 rules: бесплатный каталог не включает платный SLA

Output: «Docker сделал свой hardened-каталог бесплатным с семидневным SLA по critical».

В source L17 бесплатным стал каталог под Apache 2.0, а SLA остались в платных уровнях. Семь дней относятся к Docker Hardened Images Select. L15 отдельно задаёт семь дней BellSoft Standard и отсутствие опубликованного SLA в бесплатном Community. Output связал свойство бесплатного каталога с платным договорным обязательством. Это не просто опущенное название тарифа: смысл изменён.

### #464 examples: evaluator locality не доказывает no-egress

Output: «Код не покидает контур компании».

Source L5 говорит о коде, которым предприятия не могут делиться, локальном evaluator, генерации кандидатов API и отправке результатов обратно. L7 описывает baseline seed и problem context. Полного перечня передаваемых данных и безусловной гарантии no-egress в статье нет. Поэтому output добавляет неподтверждённую гарантию. Это **не доказательство, что закрытый код обязательно передаётся**; это отсутствие основания обещать обратное для всего процесса.

Отличие от ранее рассмотренного «закрытый код можно не отдавать» существенно: ограниченная возможность при правильном устройстве evaluator имеет некоторую опору в framing статьи; безусловное утверждение о потоке всего кода — нет.

## Особые проверки границ

- **#1107, SLO:** source L15 описывает целевую p95 полной подготовки среды. Rules сохранил модальность цели; examples опустил метрику. Нового превращения цели в достигнутый результат нет.
- **#82, by/to:** source L57 говорит о снижении производительности на величину до 40%, а не до 40% исходного уровня. Оба новых outputs обходятся без этого числа; ошибка не повторяется, но способность правильно передавать само отношение этим не доказана.
- **#82, сеть:** source L93 допускает `tc` для IP-over-IB, L95 отдельно объясняет, почему RDMA обходит `tc`. Перечень инструментов лучше не превращать в универсальную инструкцию для любого сетевого пути.
- **#826, local step vs system:** миллисекунды относятся к правке OCI manifest/config. Source L7 и L11 требуют совместимости; L7 отдельно сохраняет production testing/promotion/deployment. Ни один output явно не обещает мгновенный полный production rollout, но его отсутствие в сжатом объяснении остаётся оговоркой.
- **#1152, denominator:** source L47 задаёт условный расчёт: одна метрика, 32 ядра, нулевая стоимость бизнес-логики. L53 получает предельные значения для counter updates. Rules исключил числа, examples оставил их с неоднозначной единицей. Ошибочную трактовку автора о замедлении всего сервиса копировать нельзя.

## Формат, завершение и стоимость

Оба варианта завершили 5/5 запросов с `finish_reason=stop`. Все десять сохранили точный исходный заголовок с `**…**`. У rules 0 цитат; у examples 1, точная, но неуместная для первоначального пересказа. Это измерение формы, не доказательство авторского стиля.

Стоимость пяти rules-запусков: **$0.068765576**; пяти examples: **$0.071201680** по ledger. Малый и заранее выбранный набор не позволяет приписать различие качества именно few-shot-примерам: на случай имеется только одна реализация каждого варианта.
