1. Диагностика UI, AI-конвейера, извлечения и реальных записей БД.
2. Полный вертикальный срез UI чтения и оценок.
3. Термины, пересказы и метаданные YouTube.
4. Извлечение текстов, исправление конкретных источников.
5. Изоляция и фильтрация дубликатов/неинтересных материалов, подписки.
6. Общая проверка, безопасное развертывание, повторная проверка каждого обязательства.


## Найденные причины и выбранные исправления

- Snowflake: подтверждены французские `/fr/` версии; пользователь отдельно подтвердил скрытие французских и испанских. Правила включаются только в его workspace, исходные статьи сохраняются.
- Alibaba: первый `main` содержал навигацию, а тело лежало в `.wrap-main-left-article`. GitHub Blog: первый `article` содержал автора, тело — `.post__content`. Cloudflare: выделяем вложенный `.post-content .article-content`: внешний `.post-content` содержит гигантское меню тегов. Исходный HTML сохраняется отдельно.
- Марат Буффало: Atom выбирал первую ссылку на комментарии вместо `alternate` HTML. Все 25 старых ссылок сопоставлены по исходному Blogger post ID, исправление выполняется штатным fan-out с сохранением идентичности и состояния статьи.
- Small Decisions: в RSS указан HTTP URL brooker.co.za, запрещённый политикой обычного HTTP. Сервер отвечает редиректом на проверенный HTTPS. Добавлен конкретный публичный хост в явный allowlist; проверки каждого redirect сохраняются.
- Lovable: четыре основных раздела описывают Replit Agent, Bolt.new, Anvil и Softr; отдельно продвигается Activepieces. Финальный пересказ перечисляет эти пять вариантов отдельными пунктами и явно обозначает рекламный характер Activepieces. Сам Lovable и названия из FAQ не используются для искусственного заполнения списка.
- Reddit: публичный JSON/RSS отвечает 403 с локального и рабочего сервера; сохранённая браузерная страница — challenge без flair. Указанный пользователем URL исключается явно; общее правило использует только опубликованные Career categories/flair, без угадывания по заголовку.

Развёрнут образ `inoreader-app:reader-autopilot-final-20261005`. Последний полный release gate — `reader-release14.log`, код 0; production smoke — `reader-production-smoke-final.log`, код 0. Подписки: Meta FAIR RSS — 9 статей, PVLDB — 4052 публикации, Yandex Events — 16 событий. Дополнительный Meta AI Blog пока не получает статьи: текущий User-Agent коллектора получает HTTP 400, обычный Mozilla User-Agent при отдельной диагностике получает 200. Это ограничение дополнительного источника; обязательная подписка Meta FAIR работает. Глобальная политика HTTP не ослаблялась.

Cloudflare: приняты 67 запросов повторной обработки; на момент снимка 37 статей имеют обновлённый manifest после финальной выкладки, у всех 67 отсутствует записанная ошибка извлечения. Остальные сохраняют предыдущие тексты до завершения очереди. Реальный текст DNSSEC начинается со статьи, меню тегов отсутствует. Оригинальный HTML сохранён.

Автоматическая обработка терминов включена для нового потока и существующих статей. На момент проверки: 379 завершённых заданий текущей версии, 542 в очереди, 2 выполняются, 75 завершились явной ошибкой. Ошибки не скрываются; исходные тексты сохраняются. Очередь продолжает работу в пределах общего бюджета $3/день. Расход текущего московского дня на момент снимка: примерно $1.80, резерв примерно $0.056; бюджет не повышался.

Единственное частично заблокированное обязательство — ретроспективное определение всех Reddit Career. Правило по опубликованным categories/flair реализовано и проверено; указанный пользователем пост скрыт. Но Reddit JSON/RSS возвращают 403, а сохранённый challenge не содержит flair, поэтому достоверно разметить все исторические записи нельзя. Заголовки не используются для угадывания категории. Для завершения этой части нужен доступный источник исходного flair.
